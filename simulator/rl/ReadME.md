Read Me File
This directory contains the Reinforcement Learning (RL) interface and agent implementation integrated into the NASA DTNSim framework. The purpose of this module is to enable learning-based decision making for queue management and minimize the age of information, allowing the simulator to dynamically optimize forwarding behavior based on network conditions.

This module currently includes:
    1. RLInterface.py – Interface between DTNSim and the RL agent
    2. RLAgent.py – RL agent logic and decision policy
